# Установка LEGO Batman 2 NX

Перед началом приготовьте свою копию Xbox 360 USA с Title ID `57520817`, Media ID `1BF17B45` и локально собранный `lego-batman2-nx.nro`. В GitHub Releases доступен отдельный файл установщика `lb2-installer.nro`. [Выпуски](../../releases)

## Если игровой NRO уже есть

1. Скачайте `lb2-installer.nro` и положите его на microSD в папку `/switch/lb2-installer/`.
2. Положите свой `lego-batman2-nx.nro` в `/switch/lego-batman2-nx/`.
3. Если диск уже распакован, положите в `/switch/lego-batman2-nx/game_root/` пять файлов: `default.xex`, `GAME.DAT`, `GAME0.DAT`, `GAME1.DAT`, `GAME2.DAT`. Такой комплект занимает около 4,45 ГБ до кэша.
4. Если у вас ISO, положите его в корень SD или в одну из двух папок выше. На FAT32 используйте части по 2 ГБ с именами вида `Batman.iso.00`, `Batman.iso.01` и так далее. Для образа и установленных файлов на одной карте понадобится около 13,2 ГБ.
5. Откройте **LB2 installer** в Homebrew Menu в режиме приложения и нажмите **A**. Дождитесь `Ready` и запустите **LEGO Batman 2** с плитки HOME.

После установки и первого запуска на карте получится такая структура:

```text
switch/
├── lb2-installer/
│   └── lb2-installer.nro
└── lego-batman2-nx/
    ├── lego-batman2-nx.nro
    ├── lego_batman2.toml
    ├── game_root/
    └── userdata/
```

В hbmenu видны две плитки. **LB2 Installer** управляет установкой, **LEGO Batman 2** запускает игровой NRO напрямую. Для обычной игры удобнее плитка в HOME.

## Сборка NRO из своего ISO на компьютере

Этот способ требует отдельного комплекта исходников и инструментов. Его публикация готовится. Первый сценарий на Apple Silicon Mac использует Python 3.9+, Xcode Command Line Tools, CMake, Ninja, Git и Docker.

Утилита проверяет издание игры, извлекает исполняемый файл из ISO, собирает локальный NRO и переносит проверенные файлы на SD. Если NRO уже собран, утилита принимает его и пропускает компиляцию. В обоих случаях ISO может оставаться на компьютере. Так на карте потребуется около 4,45 ГБ до кэша.

## Повтор, обновление и удаление

- После прерванной распаковки снова нажмите **A**. Установщик использует уже проверенные части.
- Для обновления плитки нажмите **X**, затем **Y**, затем **A**. Если HOME показывает прежнюю картинку после `Ready`, перезапустите Switch.
- Чтобы обновить вручную скопированный игровой NRO, закройте игру и замените только этот файл. Держите резервную копию прежнего NRO и сохраняйте `game_root`, `lego_batman2.toml` и `userdata` на месте.
- Если игровой NRO был перенесён установщиком или утилитой компьютера, проверьте, что ваши ISO и сохранения доступны для повторной установки. С текущим NRO нажмите **X**, затем **A** в установщике. После этого установите новый комплект. Этот режим удаляет также игровые файлы, перенесённые утилитой.
- Чтобы убрать только плитку, нажмите **X**, затем **Y**. Чтобы убрать плитку и файлы, которыми управляет установщик, нажмите **X**, затем **A**. Сохранения в `/switch/lego-batman2-nx/userdata/` можно скопировать перед удалением.
- Образ ISO остаётся доступен для повторной установки. Его можно убрать с SD после прохождения проверки `Ready`.

## Как включить логи

В игре нажмите **L + R + вправо на крестовине**. Откройте **Log**, затем **log_level**, и выберите `info`. Если игра завершается до меню, выставьте `log_level = "info"` в `/switch/lego-batman2-nx/lego_batman2.toml` перед запуском. Обычный уровень — `warn`.

Для отчёта о сбое возьмите свежий `logs/lego_batman2_*.log` или `installer.log` из `/switch/lego-batman2-nx/`. При ошибке Atmosphère добавьте код ошибки или соответствующий файл из `/atmosphere/crash_reports/`. [Форма отчёта](../../issues/new/choose) · [Telegram](https://t.me/derzhivkurse_games)
